# Repository Structure Rules

- **Git Repositories**: The `backend` and `frontend` folders are separate Git repositories with their own remotes. 
- **DO NOT** run `git add`, `git commit`, or `git push` from the root `c:\whatsapp-saas` directory.
- **ALWAYS** `cd` into either `c:\whatsapp-saas\frontend` or `c:\whatsapp-saas\backend` before committing and pushing changes.
